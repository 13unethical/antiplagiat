# Пополнение корпуса антиплагиата

Положите сюда текстовые файлы (`.txt` или `.md`) — каждый станет документом
корпуса, с которым сверяются проверяемые работы.

- Имя файла = заголовок источника в отчёте.
- Язык определяется автоматически (uz-Latn / uz-Cyrl / ru).
- Файлы короче ~20 слов пропускаются.
- Подхват происходит **при старте бэкенда** (идемпотентно: по хэшу содержимого,
  дубликаты не добавляются). После добавления файлов перезапустите backend.

Чем больше корпус — тем больше находит антиплагиат. Для «живого» интернета
дополнительно включите Brave-поиск (переменная `BRAVE_API_KEY` в `.env`).
